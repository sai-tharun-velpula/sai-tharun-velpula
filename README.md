### 📌 Featured Project

**[Employee Management System (HRMS)](https://github.com/velpulasaitharun/employee-management-system)**  
A full-featured **Human Resource Management System** built with **ASP.NET Core MVC, C#, Entity Framework Core, and Microsoft SQL Server** — covering **employee records, departments, designations, attendance, leave management, payroll, role-based authentication and authorization, and audit logging**. The application follows a structured **ASP.NET Core MVC architecture** with a responsive interface for efficient day-to-day HR management.

**[Blood Donor Management System](https://github.com/sai-tharun-velpula/blood-donor-management-system)**  
A web-based **Blood Donor Management System** built with **ASP.NET Web Forms, C#, ADO.NET, and Microsoft SQL Server**. The system provides a centralized platform for managing **donor registration, donor profiles, donor directory, search and filtering, blood groups, availability, and reports**. It includes **Admin and Donor authentication with role-based access control**, donor account activation/deactivation, profile management, and **blood group and city-wise reporting**. The application follows a structured **ASP.NET Web Forms architecture** with a responsive interface for efficient donor management.
